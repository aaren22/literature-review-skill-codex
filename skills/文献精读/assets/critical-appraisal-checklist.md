# 批判性评价清单（按论文类型）

> 详见 `references/critical-appraisal.md`。
> 本文件只用于填写。

---

## 使用方法

1. 判断论文类型（实证 / 综述 / 理论 / 方法学）
2. 选对应清单
3. 每项 ✓ / ✗ / ?
4. 填完统计得分

---

## 实证研究清单（30 项）

### A. 研究设计（5 项）

# Chen2020: 行为数据与自陈量表测量的参与度相关仅 r=.34

## 核心论点

在中国 1200 名本科生样本中，LMS 行为日志数据（登录 / 发帖 / 作业）
与 SEI 自陈量表测量的参与度相关仅 r=.34，挑战了以自陈为主导的
参与度测量传统。

## 关键数据

- N=1200，单所 985 高校，Moodle 平台
- 行为-情感参与度 r=.34
- 行为-认知参与度 r=.58
- SEI α=.87

## 我的评价

- 样本够大但限于单一 LMS 平台
- 横断面设计不能推因果
- 没有对"为什么 r 这么低"的深度解释

### 填写示例

```markdown
---
type: permanent
tags: [测量, 参与度, 方法学]
created: 2025-01-18
---

# 学生参与度的自陈-行为测量一致性问题

## 定义

自陈量表测量的学生参与度与 LMS 行为日志测量的参与度之间的
**低到中等相关（r=.30-.60）**，提示两种测量方法可能测量**不同的构念**
（心理感知 vs 行为表现）。

## 核心主张

自陈与行为数据**不可直接替代**。研究参与度时应当：
1. 明确说明测量的是哪种构念
2. 混合测量作为三角验证
3. 不把自陈结果推广到行为表现（反之亦然）

## 依据

- [[Chen2020_行为自陈数据测量差异]] — 中国实证 r=.34
- [[Henrie2015_综述参与度测量]] — 143 研究的测量方法综述
- [[Fredricks2004_三维参与度奠基]] — 自陈测量传统的奠基（被间接挑战）
- [[Kim2023_四维模型提议]] — 相关讨论

## 相关概念

- [[共同方法偏差]] — 关系：因果（自陈主要偏差来源）
- [[构念效度]] — 关系：本概念是构念效度的一个子问题
- [[研究方法三角验证]] — 关系：解决本问题的方案

## 潜在应用

- **我的硕士论文方法章:** 辩护我为什么用混合测量（自陈 + 日志）
- **我的综述章:** 指出方法空白（现有中文研究 89% 自陈，缺混合）
- **引言 Move 2:** 指出测量不一致作为领域重要 gap
```

## 三类卡片的工作流

### 每日

- 读 1-2 篇论文 → 产出 1-3 张文献卡

### 每周

- 回顾本周文献卡 → 合成 1-2 张概念卡

### 每月

- 对某主题的概念卡 → 更新 / 建立索引卡

### 每季度

- 检查整个卡库的连接密度
- 补充稀疏主题的卡片
- 清理重复 / 过时卡片

## 链接语法

在 Obsidian / Roam / Logseq 中：

```
[[文件名]]                    → 双向链接
[[文件名|显示文字]]            → 自定义显示
[[文件名#小节]]               → 链接到具体小节
#标签                        → 标签
[text](file.md)              → 标准 Markdown 链接
```

## 卡片质量自检

每张卡片过这 5 条：

- [ ] **原子** — 只讲一件事
- [ ] **自主** — 脱离上下文能读懂
- [ ] **自己的话** — 不是摘抄
- [ ] **有链接** — 至少连接到 1-2 张其他卡
- [ ] **未来的我能找到** — 文件名和标签便于检索

## 常见错误

### 错误 1：文件命名不一致

- 有时用"作者年份"，有时用"日期"
- **对策：** 确定一套命名规则坚持用

### 错误 2：卡片太大

- 一张卡 1000+ 字
- **对策：** 拆成 2-3 张原子卡

### 错误 3：只建不看

- 卡片建完不再回顾
- **对策：** 每周固定时间回顾（哪怕 30 分钟）

### 错误 4：链接太少 / 太多

- 没链接 = 孤岛
- 链接太多 = 显得相关性弱
- **对策：** 每张卡 2-5 个强链接

### 错误 5：索引卡不更新

- 新概念卡加了但索引卡没更
- **对策：** 建新概念卡时立即更新相关索引卡

# 四类论文的阅读策略

> 不同类型论文读法不同。同一方法读所有论文 = 低效。

---

## 四类论文

1. **实证研究**（Empirical Research）
2. **综述**（Review）
3. **理论**（Theoretical）
4. **方法学**（Methodological）

对应不同的阅读重点和质疑方式。

---

## 1. 实证研究论文

### 特征

- 收集数据
- 使用统计 / 质性分析
- 通常 IMRAD 结构

### 第一遍重点

- **摘要** — 主要发现是什么
- **研究设计**（方法章开头）— 定量 / 定性 / 混合
- **样本描述** — N = ？ 哪类人？
- **主要图表** — 往往浓缩结果

### 第二遍重点

- **研究设计细节**
- **变量测量** — 怎么测 X 和 Y？
- **分析方法** — SEM / 回归 / 主题分析 ？
- **关键结果** — 效应量、显著性、主题

### 第三遍重点（最关键）

- **方法的严谨性：**
  - 样本代表性如何？
  - 测量效度 / 信度？
  - 统计假设是否满足？
  - 对照 / 处理变量分配是否合理？
- **结果的稳健性：**
  - 敏感性分析？
  - 效应量大小合理吗（与文献比）？
  - 置信区间 / p 值的解读？
- **替代解释：**
  - 结果有没有其他可能的解释？
  - 作者排除了哪些？没排除的是什么？
- **推论的边界：**
  - 样本 → 推论的适用范围
  - 情境 / 人群 / 时代的依赖性

### 实证研究质疑清单

| 质疑维度 | 具体问题 |
|---------|---------|
| 样本 | N 足够吗？代表性？自选择偏误？ |
| 测量 | 工具的信效度？本研究情境下还成立吗？ |
| 设计 | 因果推断是否合理？混淆变量控制？ |
| 分析 | 方法适当？假设满足？多重比较校正？ |
| 解释 | 替代解释考虑？效应量解读合理？ |
| 报告 | 数据透明（预注册 / 开源）？ |

## 2. 综述论文

### 子类

- **叙事综述**（Narrative）
- **系统综述**（Systematic，PRISMA）
- **范围综述**（Scoping）
- **整合式综述**（Integrative，Torraco）
- **元分析**（Meta-analysis）

### 第一遍重点

- **综述类型**（标题 / 摘要会说）
- **RQ**（综述要回答什么）
- **组织逻辑**（按概念 / 按时间 / 按方法？）
- **主要结论**

### 第二遍重点

- **检索策略**（系统综述必看）
- **纳入标准 / 排除标准**
- **主题组的划分**
- **核心整合性结论**

### 第三遍重点

- **批判性深度：**
  - 作者有没有评价每篇研究的方法学？
  - 有没有指出文献中的冲突和可能原因？
- **覆盖完整性：**
  - 有没有漏掉领域内的关键文献？
  - 检索字符串够宽吗？
- **组织逻辑的合理性：**
  - 按概念组织 vs 按时间 — 合理吗？
  - 主题组的划分有没有重叠 / 遗漏？
- **综述的 gap：**
  - 作者指出的 future work 方向可信吗？
  - 你能否看出作者没看出的 gap？

### 综述质疑清单

| 质疑维度 | 具体问题 |
|---------|---------|
| 类型匹配 | 综述类型与 RQ 匹配？（探索用 scoping，效应合并用 meta-analysis） |
| 检索 | 检索策略覆盖够？是否跨库？ |
| 筛选 | 筛选标准合理？是否有两人独立？ |
| 批判 | 对每篇的方法学评价够吗？ |
| 整合 | 是堆砌还是真整合（Webster & Watson 标准）？ |
| Gap | 指出的未来方向具体且可操作？ |

**特别提醒：** 系统综述要对照 PRISMA 2020 的 27 项读（见 `文献检索/references/prisma-s.md`）

## 3. 理论论文

### 特征

- 主要贡献是**概念 / 理论 / 框架**
- 不做实证（或只用实证作为 illustrative 例子）
- 通常论证结构 + 命题体系

### 第一遍重点

- **核心命题**（作者主张什么？）
- **理论边界**（这个理论适用于什么情境？）
- **关键概念**（作者定义了哪些新概念？）

### 第二遍重点

- **命题间的关系**（如果 A 则 B，如果 B 则 C...）
- **与既有理论的对话**（延续 / 挑战 / 整合？）
- **潜在的操作化**（这个理论如何可以实证检验？）

### 第三遍重点

- **逻辑一致性：**
  - 作者的推理有没有跳跃？
  - 命题间是否互相矛盾？
- **可操作化：**
  - 理论能否转化成可测量的变量？
  - 有没有具体的检验方法？
- **与既有理论的关系：**
  - 这个理论相对其他理论的优势是什么？
  - 是互补、取代还是并列？
- **理论边界：**
  - 作者说的 "boundary conditions" 合理吗？
  - 在哪些情境不适用？

### 理论论文质疑清单

| 质疑维度 | 具体问题 |
|---------|---------|
| 概念清晰度 | 核心概念定义明确且一致？ |
| 命题关系 | 命题间逻辑链完整？ |
| 可操作化 | 能想象如何实证？ |
| 边界条件 | 适用范围明确？ |
| 对话性 | 与既有理论的关系清楚？ |
| 新颖性 | 真是新贡献还是重贴标签？ |

## 4. 方法学论文

### 特征

- 核心贡献是**方法 / 工具 / 算法 / 量表**
- 可能附带应用示例
- 验证环节重要

### 第一遍重点

- **方法解决什么问题**（Motivation）
- **方法的核心思想**
- **验证方式**（用什么数据 / 基准测试）

### 第二遍重点

- **方法步骤**（清楚到能复现？）
- **关键参数**（超参数 / 默认值）
- **验证结果**（比基线好多少？）

### 第三遍重点

- **方法细节：**
  - 算法 / 公式 / 步骤完整吗？
  - 有没有隐含假设？
- **验证的充分性：**
  - 基准 baseline 合适吗？
  - 数据集代表性？
  - 评价指标合理？
- **适用条件：**
  - 哪些情境方法有效？
  - 哪些不适用？
- **与替代方法的比较：**
  - 相对优势是什么？
  - 相对劣势（作者可能不提）？

### 方法学论文质疑清单

| 质疑维度 | 具体问题 |
|---------|---------|
| 动机 | 问题真的存在且未被解决？ |
| 方法描述 | 细节足够复现？ |
| 验证 | 数据集 / 基准 / 指标合理？ |
| 适用条件 | 边界清楚？ |
| 公平对比 | 基线选得公平？超参数合理？ |
| 可用性 | 代码 / 数据是否开源？ |

## 四类论文的时间分配

假设都需到第三遍：

| 类型 | 第一遍 | 第二遍 | 第三遍 | 总 |
|------|-------|-------|-------|----|
| 实证 | 10 min | 1 hr | 4 hr | 5 hr |
| 综述 | 15 min | 1.5 hr | 5 hr | 6-7 hr |
| 理论 | 15 min | 2 hr | 4-6 hr | 6-8 hr |
| 方法学 | 15 min | 1 hr | 3-5 hr | 4-6 hr |

综述和理论通常比实证花时间更长（内容密度高）。

## 混合型论文的处理

有些论文同时是多种类型：

- **理论 + 实证** — 先理论贡献，后小实证验证
  → 读法：理论部分按理论论文读，实证部分按实证读

- **方法 + 应用** — 提出新方法，应用到某具体场景
  → 读法：方法部分按方法学读，应用按实证读

- **综述 + 理论框架** — 综述现状并提出新框架
  → 读法：综述部分按综述读，框架部分按理论读

策略：**识别论文的主要贡献类型 + 次要贡献**，分别用对应读法。

## AI 读论文的边界

**AI 能做的：**
- 第一遍：提取标题 / 摘要 / 5 个 C
- 第二遍：生成概述段落、方法描述
- 提取图表数据到表格

**AI 不能做的（至少目前）：**
- 判断样本代表性（需要领域知识）
- 识别未言之意（作者没明说的假设）
- 发现逻辑跳跃（需要深度推理）
- 判断理论边界（需要对学科的理解）
- 挑方法学缺陷（需要方法学训练）

**结论：** AI 做第一遍和第二遍的**草稿**，人做第三遍。

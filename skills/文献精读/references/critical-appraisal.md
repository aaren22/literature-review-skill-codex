# 批判性评价清单（Critical Appraisal）

> 读完论文不是结束，评价才是。
> 按论文类型选对应清单。

---

## 为什么要批判性评价

**读 ≠ 批判**

- 读 = 理解作者说了什么
- 批判 = 判断作者**说得对不对**

不做批判就等于接受所有结论。学术阅读要求**平衡理解与质疑**。

---

## 批判性评价的三层

1. **逻辑层** — 作者的论证有没有跳跃 / 循环 / 矛盾？
2. **证据层** — 作者的证据充分吗？替代解释排除了吗？
3. **推论层** — 作者的结论是否超出证据所支持的范围？

每一层都要质疑。

## 实证研究 — 30 项清单

### A. 研究设计（5 项）

- [ ] RQ 清晰、可操作化
- [ ] 假设明确、可证伪
- [ ] 研究设计与 RQ 匹配
- [ ] 样本与 RQ 匹配
- [ ] 理论框架清晰

### B. 样本（5 项）

- [ ] 样本量足够（power analysis / 饱和度）
- [ ] 抽样方法合理（随机 / 目的 / 便利性？）
- [ ] 样本代表性说明
- [ ] 自选择偏误讨论
- [ ] 纳入 / 排除标准明确

### C. 测量（5 项）

- [ ] 测量工具信度报告（Cronbach's α ≥ .70）
- [ ] 测量工具效度（内容 / 构念 / 标准效度）
- [ ] 测量在本情境下的适用性讨论
- [ ] 定性研究：编码者间一致性
- [ ] 测量时机 / 频率合理

### D. 数据分析（5 项）

- [ ] 分析方法与变量类型匹配
- [ ] 统计假设满足（正态 / 方差齐性 / 独立）
- [ ] 多重比较校正（如有）
- [ ] 效应量报告（不只 p 值）
- [ ] 缺失数据处理说明

### E. 结果报告（5 项）

- [ ] 报告了所有 hypothesis（阳性 + 阴性）
- [ ] 图表清晰且与文字一致
- [ ] 描述性统计完整
- [ ] 置信区间提供
- [ ] 敏感性分析（如需要）

### F. 解释与讨论（5 项）

- [ ] 结果解释不超出证据支持
- [ ] 替代解释讨论
- [ ] 局限性诚实列出
- [ ] 与既有文献的对话
- [ ] 实践 / 理论意义清楚

---

## 综述论文 — 20 项清单

### A. 综述设计（5 项）

- [ ] 综述类型明确（narrative / systematic / scoping / integrative）
- [ ] RQ 清楚
- [ ] 所选类型与 RQ 匹配
- [ ] 组织逻辑说明（按概念 / 时间 / 方法？）
- [ ] 是否预注册（systematic 必需）

### B. 文献检索（5 项）

- [ ] 检索策略透明（字符串 + 日期 + 库）
- [ ] 跨库 / 跨语言 / 灰色文献
- [ ] 纳入 / 排除标准明确
- [ ] 筛选流程有 PRISMA 流程图（systematic 必需）
- [ ] 同行评议搜索（PRESS 清单）

### C. 文献分析（5 项）

- [ ] 每篇纳入文献有简要评价（不是只汇总）
- [ ] 按概念 / 主题组织（非按作者）
- [ ] 冲突 / 分歧讨论（非只汇总共识）
- [ ] 方法学演变讨论
- [ ] 边界条件讨论

### D. 综合与贡献（5 项）

- [ ] 有整合性陈述（非仅汇总）
- [ ] 指出 gap 并论证
- [ ] 未来研究方向具体（不是"需要更多研究"）
- [ ] 局限性讨论
- [ ] 对理论 / 实践的贡献清楚

---

## 理论论文 — 15 项清单

### A. 概念清晰度（5 项）

- [ ] 核心概念定义明确
- [ ] 概念与既有术语的区分
- [ ] 概念可以被不同学者一致理解
- [ ] 举例说明清晰
- [ ] 中英文定义一致（中文论文）

### B. 命题体系（5 项）

- [ ] 主要命题明确列出
- [ ] 命题间关系清楚（蕴含 / 因果 / 平行）
- [ ] 命题无内部矛盾
- [ ] 论证链完整（无跳跃）
- [ ] 反方观点讨论

### C. 操作化与边界（5 项）

- [ ] 命题可以被实证检验
- [ ] 核心变量可操作化
- [ ] 理论边界（适用情境）明确
- [ ] 与既有理论的关系（延续 / 挑战 / 互补）
- [ ] 理论的实践价值 / 政策含义

---

## 方法学论文 — 15 项清单

### A. 问题与动机（5 项）

- [ ] 现有方法的具体局限说明
- [ ] 新方法的创新点明确
- [ ] 对哪些现有工作的改进
- [ ] 目标用户 / 场景清楚
- [ ] 替代方案讨论

### B. 方法本身（5 项）

- [ ] 方法细节足够复现
- [ ] 关键参数 / 超参数说明
- [ ] 隐含假设说明
- [ ] 适用条件 / 限制
- [ ] 与相似方法的关系

### C. 验证（5 项）

- [ ] 基准（baseline）合理
- [ ] 数据集代表性
- [ ] 评价指标合适
- [ ] 多个实验验证（不只一个）
- [ ] 代码 / 数据公开

## 批判的强度

**不是越严越好**。

| 强度 | 情况 |
|------|------|
| 低（只找优点） | 错，不是批判性阅读 |
| 中（平衡优缺点） | 正确，大多数情况 |
| 高（主要挑刺） | 仅当对方是你反方 / 主要比较对象 |
| 极高（否定整篇） | 罕见，除非是回应论文 |

**原则：** 对每篇都做中等强度的批判。对核心相关的论文做更深批判。

## 常见批判错误

### 错误 1：稻草人攻击

- 歪曲作者的观点再批
- **对策：** 批判前确认作者原话

### 错误 2：转移话题

- 作者在说 X，你在批 Y
- **对策：** 批判的具体性（Point-by-point）

### 错误 3：过度概括

- "所有这种研究都有问题"
- **对策：** 批判具体到这篇论文的某个细节

### 错误 4：人身攻击

- "作者显然是外行 / 是受某利益集团资助的"
- **对策：** 对事不对人，除非有明确利益冲突可追溯

### 错误 5：完美主义

- 因为作者没做到完美就否定整篇
- **对策：** 接受研究的不完美，评价是否做到了 reasonable threshold

## 从批判到写作

批判性评价的产出直接进入：

1. **文献综述章节** — 批判性综合（`文献综述写作` skill）
2. **自己论文的 Discussion** — 与既有工作的对话
3. **审稿** — 写审稿意见
4. **学术辩论** — 会议 / 讨论

**批判性评价不是为了批判而批判，是为了更精准地定位自己研究的位置。**

---

## 批判性评价 vs 欣赏

两者并非对立：

- **欣赏：** 这篇做对了什么，值得学习
- **批判：** 这篇局限是什么，可以改进

成熟的学术阅读**同时做两者**。

## 数字化工具

### Obsidian

- 每篇文献一个 note
- 清单用 checkbox
- 链接到相关的 `concept note` 和 `critique note`

### Zotero

- 用"标签"标注批判性评价结果（如 `#critical-support` / `#critical-question` / `#critical-reject`）
- 用"笔记"字段写详细评价

### Notion

- 创建数据库，每行一篇文献
- 列包括：类型 / 评价得分 / 关键缺陷 / 引用策略

## 长期建立批判性阅读习惯

### 第 1-30 天

- 每读一篇 → 至少**填 5 项清单**
- 不求全，求一致

### 第 30-90 天

- 每读一篇 → 填完整清单
- 建立自己的评价数据库

### 90+ 天

- 读速变快
- 批判性评价成为**自动化直觉**
- 读完立即能说出"这篇 3 个优点 3 个缺陷"

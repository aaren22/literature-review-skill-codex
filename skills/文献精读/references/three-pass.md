# Keshav 三遍法（The Three-Pass Method）

> **Source:** Keshav, S. (2007). How to read a paper. *ACM SIGCOMM Computer Communication Review*, 37(3), 83–84. https://dl.acm.org/doi/10.1145/1273445.1273458

---

## 核心思想

不是每篇论文都该从头到尾精读。**按深度需求分三遍**：

- **第一遍：** 5-10 分钟，判断"值不值得读"
- **第二遍：** 约 1 小时，抓主要论点
- **第三遍：** 4-5 小时，完全吸收

大多数论文**只到第一遍**就够。只有核心相关的论文才走到第三遍。

---

## 第一遍（5-10 分钟）

### 目的

快速判断这篇论文：
- 是什么类型？
- 主要贡献是什么？
- 写得好不好？
- **值不值得深读？**

### 读什么

按顺序：

1. **标题 + 摘要** (30 秒)
2. **引言** (2 分钟)
3. **所有章节标题 + 所有子节标题** (1 分钟)
4. **结论** (1 分钟)
5. **参考文献扫一遍**（知道作者引了谁）(1 分钟)
6. **数学内容**：只看有没有，不看内容

### 产出：5 个 C

- **Category**（类型）：实证？综述？理论？方法学？
- **Context**（上下文）：属于哪个文献传统？引用了哪些关键前作？
- **Correctness**（正确性）：表面看假设合理吗？
- **Contributions**（贡献）：主要贡献（作者自述）是什么？
- **Clarity**（清晰度）：写得好吗？

### 第一遍后的决定

| 5 个 C 的判断 | 下一步 |
|-------------|-------|
| 高度相关 + 清晰 + 重要 | 进入第二遍（深入） |
| 相关但方法模糊 | 进入第二遍（谨慎） |
| 边缘相关 | 标注为"可能有用"，保留标题 / 摘要笔记 |
| 不相关 / 质量差 | 放弃，不浪费时间 |

**大多数论文应该止于第一遍**。筛选效率的关键。

### 三种具体场景

**场景 1：筛 100 篇论文**
- 全部做第一遍（100 × 10 min = 17 小时）
- 筛出 20-30 篇进入第二遍
- 最终 5-10 篇进第三遍

**场景 2：快速综述**（硕士论文综述章）
- 第一遍读完 50-80 篇
- 第二遍读 15-30 篇
- 第三遍读 5-10 篇

**场景 3：深度综述**（博士论文综述章）
- 第一遍读 200-500 篇
- 第二遍读 50-100 篇
- 第三遍读 20-30 篇

---

## 第二遍（约 1 小时）

### 目的

**理解主要论点**，能向别人概述。

不追究所有细节。

### 读什么

1. **整体读**，但略过证明、公式细节、方法学 appendix
2. **仔细看图表** — 通常图表浓缩论点
3. **标记相关引用** — 标记"应该读"的参考文献（进入你的待读列表）
4. **记笔记** — 用自己的语言概述（不要照抄）

### 产出

- 一份**概述段落**：5-10 句话说清这篇论文做了什么
- 一份**方法概述**：简述用了什么方法
- 一份**主要发现**：核心 1-3 条
- **相关文献列表**：这篇引的、你应该读的

### 第二遍后的决定

| 情况 | 下一步 |
|------|-------|
| 文献综述需要引用这篇 | 只需第二遍，笔记入库 |
| 需要模仿这篇的方法 | 进入第三遍 |
| 需要引用这篇作为反方 | 进入第三遍（挑刺必须精读） |
| 只是背景知识 | 停于第二遍 |

---

## 第三遍（4-5 小时或更多）

### 目的

**完全吸收论文**。能：

- 复现方法
- 发现论文的**未言之意**（作者没明说的假设 / 局限）
- 挑出错误
- 评价论文在领域中的定位

### 读什么

1. **从头到尾**，包括所有细节
2. **模拟作者**：如果是你做这个研究，你会怎么做？哪里你会选择不同？
3. **推导公式 / 证明**（如有）
4. **记下所有质疑**（方法 / 数据 / 推论 / 表达）
5. **对比作者的做法和你的预期**

### 产出

- **完整读书笔记**（Cornell 或 Zettelkasten 格式）
- **方法评价**：样本 / 测量 / 统计 / 替代解释
- **对比 you with this paper**：你的 RQ / 方法与这篇的关系（延续？挑战？并行？）
- **引用策略**：这篇在你文献综述 / 引言中的定位（奠基？对比？反方？）

### 第三遍 = 投入的学术活动

- 通常只对 **5-30 篇核心论文**做
- 单篇 4-5 小时深读
- 可能读完还要几天消化

## 4 类论文的三遍法变体

### 实证研究论文

- 第一遍重点看：摘要 + 方法缩影 + 结果 + 结论
- 第二遍重点看：研究设计 + 样本 + 分析方法 + 关键结果图
- 第三遍重点看：方法细节 + 稳健性检验 + 替代解释的排除

### 综述论文

- 第一遍重点看：综述类型 + RQ + 结论
- 第二遍重点看：组织逻辑 + 纳入标准 + 核心主题
- 第三遍重点看：批判深度 + 与其他综述对比 + 局限讨论

### 理论论文

- 第一遍重点看：核心命题 + 论证骨架
- 第二遍重点看：命题间的关系 + 理论边界
- 第三遍重点看：逻辑一致性 + 可操作化 + 与既有理论的对话

### 方法学论文

- 第一遍重点看：方法解决什么问题 + 验证方式
- 第二遍重点看：方法细节 + 适用条件
- 第三遍重点看：数学基础 / 算法步骤 + 潜在局限 + 替代方法对比

详见 `paper-type-reading.md`。

## 三遍法的时间分配

一篇论文的**平均阅读时间分布**（假设需要到第三遍）：

| 阶段 | 时间 | 占比 |
|------|-----|------|
| 第一遍 | 10 min | 5% |
| 第二遍 | 1 hr | 25% |
| 第三遍 | 3-4 hr | 70% |

**策略：** 第一遍快筛，节省时间给第三遍。

---

## 与其他阅读法的关系

### vs SQ3R（Robinson 1946）

- SQ3R = Survey / Question / Read / Recite / Review
- 更适合**教材**阅读
- 三遍法更适合**学术论文**

### vs 批判性阅读（Critical Reading）

- 批判性阅读 ≈ 第三遍精读的评价环节
- 不是替代，是三遍法的深化

### vs 扫读（Skimming）

- 扫读 ≈ 第一遍的简化版
- 但没有 5 个 C 的结构化判断

---

## 常见错误

1. **跳过第一遍直接第三遍** — 读了很多不相关论文浪费时间
2. **每篇都三遍读完** — 对大量背景文献过度投入
3. **第一遍只读摘要** — 不够，必须加引言 / 结论 / 章节标题
4. **不做笔记** — 读完忘记
5. **笔记只是摘抄** — 没有自己的理解 / 评价

## 实操 Checklist

### 每篇论文的最小动作

- [ ] 第一遍 10 分钟 → 产出 5 个 C 判断
- [ ] 决定是否进第二遍
- [ ] 第二遍 → 产出概述 + 方法 + 发现
- [ ] 决定是否进第三遍
- [ ] 第三遍 → 产出完整 Cornell / Zettel 笔记 + 批判评价
- [ ] 归档到你的文献库（Zotero / Notion）

---

## 何时不用三遍法

- **应试类论文阅读**（考试、学习课程材料）→ 用 SQ3R
- **纯娱乐 / 探索性阅读** → 随便读
- **绝对时间紧迫（24 hr 内要引用 50 篇）** → 只做第一遍 + 精读 5 篇

---

## 长期建议

**硕博阶段每周至少**：
- 第一遍读 10-20 篇（保持对领域的广度）
- 第二遍读 3-5 篇（中等深度）
- 第三遍读 1-2 篇（深度消化）

**积累到博士阶段应有**：
- 第一遍笔记 500-1500 篇
- 第二遍笔记 200-500 篇
- 第三遍笔记 50-200 篇

这些累积就是你的**学术底气**。

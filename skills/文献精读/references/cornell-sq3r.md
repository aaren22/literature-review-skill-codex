# Cornell 笔记法 + SQ3R 阅读法

> **Cornell Source:** Pauk, W. (1962, 首版). *How to study in college*. Houghton Mifflin. (最新版 Pauk & Owens, 2014, 11th ed., Cengage)
> **SQ3R Source:** Robinson, F. P. (1946). *Effective study*. Harper & Brothers.

---

## 两者的关系

- **Cornell** — 笔记**格式**：如何组织纸面 / 屏幕
- **SQ3R** — 阅读**流程**：如何进行阅读

两者**配合使用**。Cornell 是容器，SQ3R 是过程。

## Cornell 笔记法

### 起源

康奈尔大学教授 Walter Pauk 1962 年提出。为**本科生课堂 / 教科书阅读**设计。

### 格式（一页三区）

```
┌──────────────────────────────────────────────────┐
│ 标题：[文献 / 章节名称]    日期：________        │
├────────────┬─────────────────────────────────────┤
│            │                                     │
│  Cue       │           Note-taking               │
│  (线索区)  │           (笔记主区)                │
│            │                                     │
│  关键词    │  详细笔记                           │
│  问题      │  引用                               │
│  概念      │  公式                               │
│  页码      │  图表描述                           │
│            │                                     │
│  约 1/4    │           约 3/4                    │
│            │                                     │
│            │                                     │
├────────────┴─────────────────────────────────────┤
│                                                  │
│           Summary (总结区)                       │
│           2-4 句话概括本页主要观点               │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 三区用法

**1. Note-taking（笔记主区）— 阅读时填**

- 记主要论点、数据、引用、公式
- 用符号简化（= 相等 / ↑ 增加 / ↓ 减少 / ∴ 因此）
- 每个论点分段

**2. Cue（线索区）— 阅读后填**

- 把主笔记区的要点**反刍成关键词 / 问题**
- 问题比关键词好（逼迫你复习时思考）
- 作用：日后**复习只看 Cue 区**，回忆主区内容

**3. Summary（总结区）— 完成阅读后填**

- 2-4 句话概括本页核心
- 用**自己的语言**
- 作用：日后一眼知道这篇 / 这页讲什么

### 使用流程

1. 读文献 → 主区做笔记
2. 读完 → 回看主区，抽关键词 / 问题填 Cue
3. 读完 → 写 Summary
4. 日后复习 → 遮住主区，只看 Cue，回忆内容 → 打开主区核对

### Cornell 的优势

- **强制复述**（Cue / Summary 逼你重新组织信息）
- **易于复习**（一页纸的三区结构）
- **可扩展为数字版本**（Notion / Obsidian / Word 都能排）

### Cornell 的局限

- **适合结构化内容**（教科书、综述）
- **不擅长跨文献连接**（一张 Cornell 只服务一篇文献）
- **长期积累难检索**（靠主题分文件夹）

## SQ3R 阅读法

### 起源

Francis Robinson 1946 年《Effective Study》提出。设计用于二战后美军士兵回学校的教材阅读。

### 五步法

#### S — Survey（扫描）

- **时间：** 5-10 分钟
- **做什么：** 读标题 / 章节标题 / 图表标题 / 摘要 / 结论
- **目的：** 建立整体框架

（类似 Keshav 三遍法第一遍）

#### Q — Question（提问）

- **时间：** 5 分钟
- **做什么：** 把每个章节标题转成问题
  - "Chapter 2: Research Design" → "What research design is used? Why?"
- **目的：** 带着问题读，主动阅读

#### R — Read（阅读）

- **时间：** 通读时间（1-4 小时）
- **做什么：** 认真读，回答上一步的问题
- **技巧：** 遇到重要内容 → 做笔记（Cornell 格式）

#### R — Recite（复述）

- **时间：** 读完每章节后立即
- **做什么：** 合上书，**用自己的话复述**主要内容
- **不能复述 → 没读懂** → 回去重读

#### R — Review（复习）

- **时间：** 读完 24 小时内 + 1 周后 + 1 月后
- **做什么：** 过 Cornell 的 Cue 区和 Summary 区
- **原理：** 艾宾浩斯遗忘曲线

### SQ3R 适合

- **教科书 / 综述** — 结构化强
- **考试备考** — 强制记忆
- **课堂预习** — 第一次接触新主题

### SQ3R vs 三遍法

| | SQ3R | 三遍法 |
|-|------|-------|
| 设计目的 | 教科书深读 | 学术论文快筛 |
| 第一步 | Survey（5-10 min） | 第一遍（5-10 min） |
| 核心 | 主动提问 + 深度 | 分层筛选 + 时间高效 |
| 笔记 | Cornell | 自选 |
| 适合 | 学习 / 备考 | 研究文献筛选 |

**结论：** 学术论文用三遍法，教科书 / 综述用 SQ3R。两者可结合。

## 笔记系统对比（选一个）

| 系统 | 适合 | 学习成本 | 长期价值 |
|------|------|--------|--------|
| **Cornell** | 学位论文冲刺期 / 课程学习 | 低（1 天上手） | 中 |
| **SQ3R + Cornell** | 教科书 / 系统学习 | 低 | 中 |
| **Zettelkasten** | 博士 / 长期研究 | 高（1-3 月磨合） | 高 |
| **三遍法速读卡** | 文献大批量筛选 | 低 | 中低 |

### 混合策略（推荐）

- **日常读论文：** 三遍法 + Zettelkasten（按需要到第几遍）
- **读教材：** SQ3R + Cornell
- **冲刺时期：** 只用 Cornell，简化流程

## Cornell 在数字环境的实现

### Obsidian 模板

```markdown
# [论文标题]

**Citation:** Author (Year). Title. Journal.
**DOI:** 
**Date read:** 
**Pages:** 

---

## Cue | 线索

- [关键词 1]
- [问题 1]
- [p.35 主要发现]
- [[连接到其他笔记]]

---

## Note-taking | 笔记

[详细笔记...]

---

## Summary | 总结

[2-4 句话概括]
```

### Notion 数据库版本

- 三列数据库：Cue / Notes / Summary
- 标签 / 链接 / 按日期排序

### Word 表格版本

- 插入 3x1 表格
- 按 Cornell 布局设置

## 实操建议

### 每天的最小量

硕博生每周至少：

- 第一遍读 10-20 篇（可能产出 2-4 篇 Cornell 笔记）
- Cornell 详细笔记 3-5 篇

### 笔记本数量

- 一门课 / 一个项目 = 一个笔记本文件夹
- 文件夹内按**主题**而非**时间**组织
- 跨主题的笔记用链接

### 复习频率

- 1 天后：快速过 Cue（5 min）
- 1 周后：再过 Cue + Summary（10 min）
- 1 月后：读 Summary 决定是否需要重读（2 min）
- 考试 / 写作前：完整复习主区

## 常见错误

### 错误 1：先写 Summary 再做笔记

违反 Cornell 流程。Summary 应该是**结果**，不是**出发点**。

### 错误 2：Cue 区只放关键词不放问题

- 关键词让你认出来但不帮助主动回忆
- **问题强制你思考**，记忆更牢

### 错误 3：主区做得太完整（像摘抄全文）

- Cornell 不是复印机
- 主区应该抓要点 + 你的理解

### 错误 4：Summary 写得像主区缩水版

Summary 应该是**评价 + 要点**，不只是压缩。

**差的 Summary：** "本章讨论了三维参与度模型的测量方法。"
**好的 Summary：** "三维模型测量长期依赖自陈量表，近期 Chen (2020) 的低相关性挑战这一主流。"

## 从 Cornell 毕业到 Zettelkasten

当你：

- Cornell 积累 200+ 页
- 开始发现同一概念反复出现
- 开始想在不同课题间建立连接

→ **开始尝试 Zettelkasten**（见 `zettelkasten.md`）

Cornell 可以作为 Zettelkasten 的**文献卡输入**。Zettelkasten 的概念卡来自对多张 Cornell 笔记的整合。

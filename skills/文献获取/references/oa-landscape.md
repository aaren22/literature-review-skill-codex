## Open Access 基础

### 定义（Suber 2012）

**Open Access (OA)** = 学术文献**免费**且**无使用限制**（Creative Commons 许可）。

### 六种 OA 类型

| 类型 | 定义 | 特征 |
|------|------|------|
| **Gold OA** | 期刊整本开放 | 论文都免费（但常需 APC 付费给期刊） |
| **Green OA** | 作者自存档 | 作者上传到机构库 / 个人主页（通常有 embargo 期）|
| **Hybrid OA** | 订阅期刊中选择性付费开放 | 同一期刊混合 |
| **Diamond OA** | 免费且无 APC | 常由学术机构 / 非营利组织运营 |
| **Bronze OA** | 免费但无明确许可 | 不符合严格 OA 定义，但能访问 |
| **Black OA** | 非法灰色（如 Sci-Hub） | 不在本节讨论 |

### 全球 OA 现状（Piwowar 2018）

- 约 **28% 的学术论文**有某种 OA 版本
- 近期（2010+）论文 OA 率更高
- Hybrid / Green 占最大比例
- OA 论文的**引用率**显著高于非 OA 论文

### 机构库 (Institutional Repository)

大多数研究型大学有机构库（IR），存储本校研究者的 OA 版本。

- 访问方式：Google Scholar 搜论文时常有"[PDF]"链接指向某校 IR
- 代表：MIT DSpace, Harvard DASH, 各大学的 DSpace

## OA 工具

### Unpaywall（必装）

- 浏览器插件（Chrome / Firefox）
- 在期刊页面自动显示"绿色锁"图标 → 表示有 OA 版
- 点击 → 直接跳转 PDF
- 覆盖 50-70% 的非订阅论文
- 免费

### Open Access Button

- 类似 Unpaywall
- 额外：对没 OA 的论文支持**自动向作者请求**（Request a copy）
- 免费

### Lean Library / Kopernio

- 整合机构订阅 + OA
- 自动识别你所在机构的访问权限

### Google Scholar

- 论文搜索结果右侧的 "[PDF]" 是 OA 版链接
- 显示所有已索引的公开版本
- 免费

### ResearchGate / Academia.edu

- 学术社交网络
- 作者可上传自己的论文
- 如未上传：可点击"Request full-text"请求作者
- 免费注册

## 预印本的处理规则

### 查预印本的 5 步

1. 知道论文的 DOI / 标题
2. 到相关预印本库搜（arXiv / bioRxiv / SSRN 等）
3. 找到预印本版本
4. 对比预印本版与期刊版**是否一致**（标题 / 摘要 / 主要数据）
5. 引用时注明：

   ```
   Smith, J. (2024). Title. *Journal Name*, 12(3), 45-67.
       Preprint available at: https://arxiv.org/abs/2401.xxxxx
   ```

### 预印本引用陷阱

1. **引用预印本但已有期刊版** → 应引用期刊版（更权威）
2. **预印本已被撤稿** → 检查期刊最新状态
3. **预印本与期刊版数据不一致** → 需要判断哪个是最终版

## 期刊的 OA 政策查询

### Sherpa Romeo

- sherpa.ac.uk/romeo
- 查询期刊的 OA / 自存档政策
- 告诉你哪个版本（preprint / accepted manuscript / published version）可以放机构库

### 常见期刊 OA 政策

| 出版社 | 预印本 | 接收后版 | 发表版 |
|-------|-------|---------|--------|
| Elsevier | ✓ | ✓（embargo 12-24 月）| ✗（除非付费）|
| Springer | ✓ | ✓（embargo 6-12 月）| ✗ |
| Wiley | ✓ | ✓（embargo 12 月）| ✗ |
| Taylor & Francis | ✓ | ✓（embargo 12-18 月）| ✗ |
| 学会出版（APA / IEEE）| 各学会不同 | 通常 6-12 月 | ✗ |

**含义：** 论文发表 1 年后，作者版本可能已进入机构库或 ResearchGate，Green OA 可获取。

## 实操建议

### 标准流程

1. 在 Google Scholar 搜论文标题
2. 看右侧是否有 [PDF] 链接 → 有 → 下载，结束
3. 装 Unpaywall，在期刊页面看绿色锁 → 有 → 下载
4. 尝试 OA Button → 有 → 下载
5. 搜作者主页 / 预印本 → 有 → 下载
6. 到 Level 4 作者请求邮件

### 高效率

- **建立工作流：** 每次拿到 DOI 先跑这 4 步（<3 分钟）
- **批量处理：** 用 Zotero + Unpaywall Finder 批量查 OA 版
- **预印本查全：** 不止 arXiv 一处，多库交叉

### 记录

- **每篇论文保存最终版信息**（哪个版本、来自哪里、获取日期）
- **引用时注明版本**

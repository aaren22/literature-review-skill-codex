# 中国本地化文献获取渠道

---

## 一览表

| 渠道 | 适用场景 | 费用 | 速度 |
|------|---------|------|------|
| 校图书馆订阅 | 本校订阅库 | 免费 | 即时 |
| 校图书馆 ILL | 本校未订阅期刊 | 免费或少量工本费 | 3-7 天 |
| CALIS | 跨校期刊 / 书 | 通常免费 | 1-3 天 |
| NSTL | 科技文献 | 免费 | 1-3 天 |
| 读秀 / 超星 | 中文书 | 订阅后免费 | 即时 |
| 作者请求 | 任何论文 | 免费 | 1-3 天 |

---

## 校图书馆 ILL（馆际互借）

### 什么是 ILL

- 本校图书馆向其他图书馆请求文献的服务
- 中国高校普遍提供
- 常用于：
  - 本校不订阅的期刊
  - 外校学位论文
  - 国外罕见书籍

### 申请流程

1. 进入本校图书馆"馆际互借"页面
2. 注册 / 登录
3. 提交申请单：
   - 文献标题
   - 作者
   - 发表年份
   - 期刊 / 出版社
   - DOI（如有）
   - 紧急程度
4. 等待（通常 1-7 天）
5. 收到 PDF / 纸质复印件

### 注意事项

- 申请量有上限（各校不同，通常每学期 10-30 篇）
- 复印版权费 0-20 元 / 篇
- 不是所有文献都能申请到（外校不公开的也不行）

## CALIS（中国高等教育文献保障系统）

### 什么是 CALIS

- **教育部**主导的高校图书馆联合体
- 连接 1000+ 所中国高校图书馆
- 提供**文献传递服务**

### 使用流程

1. 进入本校图书馆网站
2. 找"CALIS"或"文献传递"入口
3. 登录（本校账号）
4. 搜你要的文献
5. 发起请求
6. CALIS 系统自动分配给有订阅的合作校
7. 收到 PDF（通过邮箱或下载链接）

### 覆盖范围

- 期刊论文
- 学位论文
- 会议论文
- 图书章节

### 限制

- 整本书不能复印（版权）
- 某些新文献有时间延迟（大约 6-12 月）

## NSTL（国家科技图书文献中心）

### 什么是 NSTL

- 由**国家科技部**主导
- 面向科技领域文献服务
- **非校际的国家级补充**

### 使用流程

1. 访问 www.nstl.gov.cn
2. 注册账号（需实名）
3. 搜文献
4. 提交申请
5. 收到 PDF（邮箱）

### 覆盖

- 科技期刊（以 SCI / 工程类为主）
- 技术报告
- 标准（国标）

### 优势

- **免费**
- **速度快**（通常 1-3 天）
- 不受校际限制

### 限制

- 人文社科覆盖弱
- 需要实名账号

## 读秀 / 超星

### 读秀

- **中文图书**最全的库
- 搜索中文图书全文
- 发现图书 → 可以：
  - 借实体（如果本校图书馆有）
  - 下载章节（PDF，有配额）
  - 申请馆际

### 超星

- 读秀的母公司
- 电子图书阅读平台（200 万+ 中文电子书）
- 图书馆订阅后免费使用

### 如何用

1. 通过本校图书馆进入读秀 / 超星
2. 搜书（标题 / 作者 / 主题）
3. 预览 → 下载章节 / 借阅整本

### 限制

- 每天 / 每月有下载配额
- 不能一次下载整本书（防盗版）
- 部分新书不在超星

## CNKI / 万方 的特殊获取

### 订阅获取

- 机构订阅（大多数高校）
- 个人订阅（年费 300-600 元）

### 没订阅时

1. **作者请求** — 发邮件给作者
2. **图书馆代下载** — 本校图书馆若订阅，通过图书馆员
3. **国家哲学社会科学文献中心** — 免费（www.ncpssd.org），收录部分 CNKI 期刊
4. **短期订阅** — CNKI 按次购买（5-25 元 / 篇）

## 具体文献类型的中国获取策略

### 中文期刊论文

- **主战场：** CNKI / 万方
- **订阅不够：** CALIS 传递 / 作者请求
- **免费渠道：** 国家哲学社会科学文献中心

### 中文学位论文

- **CNKI 博硕学位论文库** — 最全
- **万方学位论文** — 补充
- **各校本地库** — 部分学校有机构库
- **ProQuest** — 海外中国学生学位论文

### 中文书籍

- **超星 / 读秀** — 电子
- **校图书馆实体借阅**
- **JD / 当当购买**（最后一招）
- **国家图书馆** — 实地访问最全

### 英文文献的中国获取

- **校订阅的英文库** — WoS / Scopus / PubMed 等
- **CALIS 传递** — 本校未订阅的跨国期刊
- **NSTL** — 科技类强项

## 导师 / 实验室的资源

### 合作资源

- 导师可能有其他学校的合作账号（通过合作项目）
- 同门师兄师姐可能有某校订阅
- 实验室可能订阅某几个关键期刊

### 使用建议

- 别不好意思问导师 / 师兄师姐
- 尊重版权，不要把别人账号转给第三方
- 获得 PDF 后保存到自己 Zotero

## 法律与伦理红线

### 合规

- ✅ 通过订阅访问
- ✅ 通过 OA / 预印本
- ✅ 通过作者请求
- ✅ 通过 ILL / CALIS / NSTL

### 灰色区

- ⚠️ 使用 Sci-Hub / Library Genesis（各国法律不同，中国法律和机构态度复杂）
- ⚠️ 大规模爬取数据库（违反服务条款，可能构成学术不端）

### 明确不合规

- ❌ 破解数据库防护
- ❌ 通过贿赂 / 欺骗获得订阅账号
- ❌ 把订阅账号商业化转售

详见 `ethics-discussion.md`。

## 特殊情况处理

### 情况 1：论文存在但访问不了任何渠道

- 再尝试作者请求（认真写邮件，1-3 天内回复率 > 50%）
- 查该作者是否在 ResearchGate 上传
- 在本校图书馆提交 ILL

### 情况 2：这是一本书的一章，整本买太贵

- ILL 申请**单章节**复印（通常合规）
- 去图书馆借实体 → 扫描该章节（合规）
- 在 Amazon / Google Books 预览（部分章节免费）

### 情况 3：这是一份过去的会议论文

- 查会议是否有正式 proceedings（IEEE / ACM）
- 搜作者的个人主页
- 联系会议秘书处

### 情况 4：这是政府 / 非营利组织的报告

- 通常**官方网站免费**
- 如果过时被撤，查互联网档案（archive.org）

### 情况 5：这是一份标准（如 GB/ISO/IEEE）

- 国标：全国标准信息公共服务平台（部分免费）
- ISO：贵，通过图书馆 ILL
- IEEE：订阅或单篇购买

## 实操 Checklist

遇到论文下不到，按顺序走：

- [ ] 校图书馆订阅？（Level 1）
- [ ] Google Scholar 有 [PDF]？
- [ ] Unpaywall 有绿锁？
- [ ] 预印本库有？
- [ ] 作者主页有？
- [ ] ResearchGate 有？
- [ ] 发邮件给作者？
- [ ] 发 ILL 申请？
- [ ] 发 CALIS 申请？
- [ ] 发 NSTL 申请？

**做到这 10 步，99% 的论文都能拿到。** 剩下 1% 考虑换文献。

# Sci-Hub 及灰色渠道的学术讨论

> **核心参考：** Himmelstein, D. S., Romero, A. R., Levernier, J. G., Munro, T. A., McLaughlin, S. R., Greshake Tzovaras, B., & Greene, C. S. (2018). Sci-Hub provides access to nearly all scholarly literature. *eLife*, 7, e32822. https://doi.org/10.7554/eLife.32822

---

## 为什么需要讨论

Sci-Hub / Library Genesis 等灰色渠道广泛存在，**拒绝讨论它们不能让它们消失**。作为科研工作者，你应该：

1. 理解它们的**学术现象级影响**
2. 知道**法律与伦理的边界**
3. 明确本产品的立场（**不推荐使用**）

**本文件仅作为学术讨论的背景材料**，不提供访问链接或使用指南。

---

## Sci-Hub 是什么

由 Alexandra Elbakyan 于 2011 年创建的论文开放平台。通过各种手段获取出版社的 PDF，供全球免费访问。

### 规模（Himmelstein 2018）

- 截至 2017 年，Sci-Hub 覆盖 85.1% 的现存学术论文
- 对订阅期刊的覆盖接近 95%
- 月下载量以亿计

### 法律状态

- **美国、多数西欧国家、日本：** 违法（侵犯版权）
- **俄罗斯：** 运营但面临法律挑战
- **中国：** 法律上灰色，机构态度不一
- **全球整体：** 多数国家的法律不允许

### 伦理争议

**支持方论点：**
- 学术应该开放（Suber OA 运动的延伸）
- 订阅费过高（部分期刊年费 $10,000+）
- 全球南方研究者受益
- 加速科学传播

**反对方论点：**
- 违反版权法
- 伤害出版社商业模式
- 某些安全风险（恶意代码）
- 不是"真 OA"（没有明确许可）

## Himmelstein 2018 的贡献

这是关于 Sci-Hub 的**学术级实证研究**，发表于 eLife（OA 期刊）。

### 核心发现

1. Sci-Hub 覆盖率异常高（85%+）
2. 对所有学科几乎均匀覆盖
3. 特别覆盖订阅昂贵的期刊（Elsevier / Wiley / Springer）
4. 与机构订阅的重叠度：Sci-Hub 覆盖甚至超过一些顶尖大学订阅

### 对学术传播的启示

- 付费墙在实践中失效
- OA 运动的压力增强
- 出版社商业模式被挑战

### 研究方法

作者公开了数据和代码，用的是合法数据分析方法（不是下载 Sci-Hub 论文）。本身是一篇规范的学术研究。

## 学术机构的立场

### 中国高校

- **教育部** 无明确禁用（2025 年 4 月现状）
- **部分高校** 在学术诚信规范中提到合规获取
- **实际执行：** 使用 Sci-Hub 在中国高校中广泛存在，但通常不写在论文里

### 国际机构

- **美国高校：** 常明确禁止，违规有处罚（警告到开除）
- **欧盟：** 部分高校封锁 Sci-Hub 域名
- **期刊：** Elsevier 曾诉讼 Sci-Hub，赢了但执行困难

## 实用建议（本 skill 的立场）

### 推荐的

1. **穷尽合规渠道**（本 skill Level 1-5）
2. **作者请求**（回复率 50%+，不用走灰色）
3. **图书馆 ILL**（慢但免费合规）
4. **OA 版本查找**（Unpaywall / OA Button / 预印本）

### 不推荐（不代表否定使用者的选择）

- 使用 Sci-Hub / Library Genesis 获取文献

**本产品的立场：** 不把 Sci-Hub 作为推荐获取渠道。不列入 Level 1-5。

**用户自己如果选择使用：** 
- 注意本机构 / 本国法律
- 写论文时不要**引用 Sci-Hub 作为来源**（引用正式出版来源，即使你是通过 Sci-Hub 看到的）
- 尊重版权，不批量下载

## 引用规范（如有人问）

**错误：**
```
Smith (2020). [from Sci-Hub]
```

**正确：**
```
Smith, J. (2020). Title. Journal Name, 12(3), 45-67. 
   https://doi.org/10.xxxx/xxxx
```

引用文献时**永远引用原始期刊 / 出版来源**，无论你是从哪个渠道看到 PDF 的。这是学术诚信的基本要求。

## Library Genesis（LibGen）

类似 Sci-Hub 但覆盖书籍（不仅论文）。法律与伦理问题基本一致。

## 替代性开放获取倡议

如果你同意"学术应该开放"但不想用 Sci-Hub，可以：

1. **支持 OA 期刊**（PLOS / eLife / Scientific Reports 等投稿）
2. **预印本** — 自己的论文先发 arXiv / bioRxiv / SSRN
3. **Green OA 自存档** — 发表后上传到机构库
4. **推动机构订阅变革** — 参与 Read & Publish 协议讨论
5. **OA2020 倡议** — 全球 OA 推动运动

## 快速问答

**Q: Sci-Hub 有没有恶意代码？**
有安全专家讨论过但无大规模确证。不建议使用。

**Q: 使用 Sci-Hub 会被学校发现吗？**
校园网 IP 访问会留日志。被发现概率低但存在。

**Q: 我的导师用 Sci-Hub，我用了算不算学术不端？**
学术不端的定义是伪造数据 / 抄袭 / 挂名等。使用灰色渠道获取论文不直接算学术不端，但可能违反版权法与本校规定。

**Q: 我的论文综述里读过的论文是从 Sci-Hub 来的，怎么办？**
引用时引用正式期刊来源。如果审稿人问"你有订阅 X 期刊吗"，你应该用其他合规渠道重新核实，确保看到的是正式版。

**Q: 本产品会升级支持 Sci-Hub 检索吗？**
不会。本产品只推荐 Level 1-5 合规渠道。

## 结语

本 skill 的立场是**推动开放学术**，但**通过合规渠道**：作者请求、OA 运动、机构订阅变革、Green OA 自存档。

如果你发现 Level 1-5 都走不通，**先考虑是否需要换参考文献**（有时不是必须引这一篇）。实在必须，请用你自己的判断，但不要说是本 skill 推荐的。

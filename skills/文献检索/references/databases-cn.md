# 中文学术数据库使用指南

---

## 四大中文库对比

### CNKI（中国知网）

**全称：** 中国国家知识基础设施

**覆盖：**
- 中文核心期刊（90%+）
- 硕博学位论文（最全）
- 会议论文
- 报纸、年鉴、工具书

**优势：**
- **最大最权威**的中文学术库
- 收录中国学术期刊最全
- 被引数据国内公认
- 有"中国期刊全文数据库"、"中国优秀硕士学位论文全文数据库"、"中国博士学位论文全文数据库"等子库

**劣势：**
- 订阅贵（对个人用户）
- 下载受限（非订阅用户）
- 检索语法不如国际库灵活
- 导出到 Zotero 需插件

**检索语法：**
```
SU = '数字化转型' AND SU = '中小企业' AND YE BETWEEN ('2020', '2024')
```

- `SU` = 主题（关键词+摘要+标题）
- `TI` = 标题
- `AU` = 作者
- `KY` = 关键词
- `AB` = 摘要

**推荐：** 中文综述必检。如果只能选一个中文库，选 CNKI。

---

### 万方数据

**覆盖：**
- 中文期刊（覆盖略逊 CNKI）
- 学位论文（与 CNKI 部分重合，部分互补）
- 专利、会议、科技报告、标准

**优势：**
- 订阅相对便宜
- 非期刊类资源（专利 / 标准 / 政府报告）比 CNKI 强
- 部分高校只订阅万方

**劣势：**
- 期刊收录数量少于 CNKI
- 国外学者引用相对少

**检索语法：** 类似 CNKI，但略有不同

**推荐：** 作为 CNKI 的补充。学位论文检索时强烈推荐同时用。

---

### 维普（重庆维普）

**覆盖：**
- 中文期刊（偏工科）
- 会议论文

**优势：**
- 工科学科覆盖强
- 历史悠久，部分早期期刊 CNKI 未收

**劣势：**
- 社科覆盖弱
- 订阅率低于 CNKI / 万方

**推荐：** 工科 / 医学综述时作为补充。社科可跳过。

---

### 超星（含读秀）

**覆盖：**
- **电子图书**（最大中文图书库）
- 期刊、学位论文（与 CNKI 重合）

**优势：**
- **书**的覆盖全（200 万+ 中文图书）
- 读秀可搜图书全文
- 非期刊类资源丰富

**劣势：**
- 期刊检索不如 CNKI 方便

**推荐：** 当综述需要引用中文专著时用。系统综述一般不用。

---

## 其他中文资源

### 中国生物医学文献库（CBM）

- 医学专业，中文 MeSH 词表
- 医学综述**必检**

### 国家哲学社会科学文献中心

- **免费**
- 社科期刊集合
- 适合无订阅用户

### 中国科学引文数据库（CSCD）

- 中科院建设
- 中文核心引文数据
- 评价中文期刊影响力的指标

### CSSCI（南大核心）

- 南京大学建设
- 社科引文索引
- 评价社科期刊水平

### 百度学术 / 搜狗学术

- 免费搜索入口
- 覆盖范围广但精度不如 CNKI
- 适合快速探索，不适合正式检索

---

## 推荐组合（中国作者）

### 硕士论文综述章

CNKI + 万方 + Web of Science（国际文献）+ 目标学科 1 英文专业库

### 博士论文综述章

CNKI + 万方 + 维普（工科）或 CBM（医学）+ Web of Science + Scopus + 目标学科 2 英文专业库

### 投中文核心期刊

CNKI + 万方 + 维普 + CSSCI / 中国核心期刊目录 + Web of Science（少量国际）

### 投 SSCI / SCI

CNKI + 万方（展示对中文文献的覆盖）+ 英文主流 4-5 库

## 中文检索特殊技巧

### 同一概念的中文变体

中文术语常有多种说法，要穷尽：

- "人工智能" = "AI" = "智能技术" = "机器智能"
- "大学生" = "本科生" = "高校学生" = "大专院校学生"
- "城乡差距" = "城乡不平等" = "城乡二元结构"

### 同一概念的中英混用

中文论文标题 / 摘要常混用中英：
- "AI 在教育中的应用"（AI 是英文）
- "ChatGPT 与大学写作"

检索时搜**中文词 + 英文词** 双语组合。

### 中文受控词

- CNKI 主题词
- CBM MeSH 中文版
- 中图法分类号

### 中文与英文互译的坑

- 中文"学生参与度" ≠ 英文 "student engagement"（英文还有 "involvement"、"participation" 等近义）
- 搜中文库用"参与度"，搜英文库用 "engagement" + "involvement"

---

## 常见错误

1. **只搜 CNKI 不搜万方** — 学位论文大量遗漏
2. **英文综述完全不搜中文库** — 不合规（系统综述要求覆盖"所有相关语言"）
3. **用中文术语直接机翻搜英文库** — "学生参与度" → 搜 "student participation" 漏掉 engagement
4. **不用 CSSCI / 中科院分区筛选** — 搜到大量非核心期刊论文
5. **认为"中国学者用中文库就够了"** — 国际顶刊大量中文作者，必须搜英文库

---

## 合规与伦理

- 中国有些数据库要求 IP 认证（必须校园网或 VPN）
- 爬虫抓取 CNKI / 万方数据违规（学术不端 + 数据库服务条款）
- 个别中文期刊不上任何数据库，需要直接访问期刊官网（如某些高校学报）

# 概念矩阵（Concept Matrix）

> **Source:** Webster, J., & Watson, R. T. (2002). Analyzing the past to prepare for the future: Writing a literature review. *MIS Quarterly*, 26(2), xiii–xxiii.

---

## 为什么要做这个

**Webster & Watson 2002 的核心论断：**
> 真正有效的文献综述按**概念**组织，不是按**作者**组织。

按作者组织 = 堆砌式综述（最大病）
按概念组织 = 批判性综合（目标）

概念矩阵是从"一篇篇论文笔记"过渡到"按概念组织写作"的**必经中间件**。

---

## 矩阵结构

```
              概念1  概念2  概念3  概念4  概念5  概念6
论文 A          ✓     ✓                 ✓
论文 B                ✓     ✓
论文 C          ✓            ✓     ✓
论文 D                       ✓           ✓
论文 E                              ✓    ✓     ✓
```

- **行** = 你读过的每篇论文
- **列** = 你从论文中提取的概念 / 主题 / 变量 / 方法
- **单元格** = 该论文对该概念的立场/发现/证据强度

**写作时：读矩阵的列（不是行）。每一列 → 一段综述。**

## 字段填写规范

### 文献栏

格式：`作者 (年份)`
多作者：`第一作者 et al. (年份)`
中文文献：`张三 (2023)` 或 `张三等 (2023)`

### 研究类型栏

从以下选择：
- **定量** — 实验 / 调查 / 二次数据
- **定性** — 访谈 / 民族志 / 个案 / 扎根理论
- **混合** — 顺序 / 并行 / 嵌入
- **理论/概念** — 纯理论建构，无实证数据
- **综述/整合** — 已有综述文献
- **方法学** — 方法论开发或讨论

### 概念栏

每个单元格可填：
- `✓` = 讨论了这个概念
- `+` = 正向支持
- `−` = 负向/反对
- `?` = 混合/不确定结果
- `N/A` = 没讨论

**或更丰富：** 填一句话（"中介作用显著 β=.34"/"未发现关系"/"理论提出但未实证"）

### 方法学栏

常见标注：
- 定量：实验 / 问卷 / 二手数据 / 元分析 / SEM / 回归 / 多层次模型 / 机器学习
- 定性：访谈（半结构 N=？）/ 参与观察 / 文本分析 / 个案研究 / 民族志
- 混合：顺序解释 / 顺序探索 / 并行三角 / 嵌入设计

### 样本栏

格式：`N=数量 样本描述`
例：`N=350 中国大学本科生` / `N=20 中学教师（北京、上海）` / `N=15000 SCI 论文（WoS）`

### 关键结论栏

一句话，不超过 30 字。
- 定量：关键效应 + 统计结论
- 定性：核心发现/主题
- 理论：提出的核心命题

### 局限栏

注意的方法学/情境局限，用于后续批判。

## 概念提取方法

### 方法 1：从 RQ 自顶向下

从你的研究问题倒推：
- RQ 涉及变量 A、B、C → 概念列 = A、B、C、A-B 关系、A-C 关系、B-C 关系
- 加上理论/方法维度

### 方法 2：开放编码自底向上

（像扎根理论）：
1. 读前 10 篇论文，每篇提取 5-10 个关键概念词
2. 合并同义 / 近义
3. 删除太笼统（"学习"）和太具体（"某量表 3 题"）
4. 剩 15-30 个概念 → 初步列集合

### 方法 3：混合（推荐）

先用方法 1 定骨架（5-8 个核心概念列），再用方法 2 补 5-10 个浮现概念列。

## 填写示例（教育领域「在线学习学生参与度」主题）

| # | 文献 | 类型 | 参与度定义 | 行为维度 | 情感维度 | 认知维度 | 平台影响 | 教师角色 | 测量方法 | 样本 | 关键结论 | 局限 |
|---|------|------|-----------|---------|---------|---------|---------|---------|---------|------|---------|------|
| 1 | Fredricks et al. (2004) | 理论 | 三维模型 | ✓ | ✓ | ✓ |  |  | 量表开发 | N/A | 提出三维框架 | 在线情境未检验 |
| 2 | Henrie et al. (2015) | 综述 |  | ✓ | ✓ | ✓ | ✓ |  | 综述 143 篇 | 文献 | 在线参与度研究碎片化 | 截至 2014 |
| 3 | Chen (2020) | 定量 | 采用 Fredricks | ✓ | ✓ |  | LMS 数据 |  | 行为日志 | N=1200 | 行为参与度 ≠ 情感 | 未测认知 |
| 4 | Zhang (2022) | 定性 | 批评三维模型 |  | ✓ |  |  | ✓ | 访谈 | N=30 教师 | 教师在情感维度关键 | 中国情境特殊 |
| 5 | Kim et al. (2023) | 混合 | 扩展四维 | ✓ | ✓ | ✓ | ✓ |  | 问卷+访谈 | N=500+20 | 社交维度需补入 | 时间跨度短 |

**读矩阵的列生成段落示例：**

**概念列「情感维度」→ 综述段落：**

> 情感维度是在线学习参与度研究中争议最多的部分。Fredricks 等（2004）最早将其纳入三维框架，但定义偏重于传统课堂情境。Henrie 等（2015）的系统综述指出，143 项研究中测量情感维度的方法差异显著，同一概念在不同研究中指代从"兴趣"到"归属感"到"学业情绪"不等。Chen（2020）的大规模日志分析表明，行为参与度与情感参与度相关但不等同，r=.34，意味着二者需分别测量。在中国情境下，Zhang（2022）的质性研究进一步提出，教师的情感支持可能是影响学生情感参与度的关键变量，这一发现补充了以西方情境为主的 Fredricks 原始框架。Kim 等（2023）的混合研究则将"社交情感"作为新维度独立出来，与原有情感维度加以区分。这些研究共同揭示，尽管情感维度的重要性已成共识，但其**测量与边界仍在争议**，特别是在文化情境与平台类型影响下的差异尚未系统检验。

**对比：按论文顺序写的堆砌式段落（错误示范）：**

> Fredricks 等（2004）提出了三维框架。Henrie 等（2015）做了综述。Chen（2020）用了日志分析。Zhang（2022）做了质性研究。Kim 等（2023）用了混合方法……

## 扩展：Torraco 综合矩阵（更深一层）

Torraco (2005, 2016) 在概念矩阵基础上加两列：

| 论文 | 概念 1 | ... | **理论立场** | **方法学归属** |

**理论立场栏：** 研究者所处的理论传统（如"社会认知论"/"建构主义"/"系统理论"）
**方法学归属栏：** 研究方法的流派（如"定量 + 实证主义"/"定性 + 诠释学"）

当你要写**方法学综述**或**理论综述**时，这两列能帮你梳理方法/理论演变脉络。

## 实操提示

1. **不要追求完美。** 第一版矩阵一定有漏洞和错分类，正常。跑完 Step 2 概念分组后回头修是常态。
2. **不要超过 15 列。** 超过说明概念粒度太细，需要合并。
3. **不要超过 150 行。** 博士论文综述章最多引 150 篇左右；如果读了 300 篇，说明没筛选。
4. **先填关键列（概念 1-5 + 方法）**，最后补次要列（局限、边界）。
5. **用 Excel 或 Notion 数据库做，不要用 Word 表格**——列要能排序筛选。
6. **导出 Markdown 粘贴到综述 working draft 里**，按列展开写段落。

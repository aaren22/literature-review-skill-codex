---

## 填写说明

- **行 = 每篇论文**
- **列 = 你从论文提取的概念/主题/变量/方法**
- **单元格 = 该论文对该概念的立场 / 结果 / 证据强度**

单元格填：
- `✓` 讨论了
- `+` 正向支持
- `−` 负向 / 反对
- `?` 混合 / 不确定
- `N/A` 没讨论
- 或一句话（"β=.34 显著"/"定性识别 3 机制"）

## 填写检查

- [ ] 每篇论文的笔记都已完成（用过 `文献精读` skill）
- [ ] 概念列数 ≤ 15（太多说明粒度过细，要合并）
- [ ] 每个概念列有明确定义，不是"情感因素"这种模糊词
- [ ] 相同概念不同论文的填法一致（都用 `+/−` 或都用一句话）
